# MCJ Manager 1.0.2

## Deutsch

Sicherheitsupdate für zlib. Behebt die beiden gemeldeten Sicherheitslücken CVE-2026-76844 und CVE-2026-85091 in der Kompressionsbibliothek des Manager-Images.

Bitte eine vorhandene Installation über die [Update-Anleitung](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/v1.0.2/docs/AKTUALISIEREN.md) aktualisieren. Welt, Mods und Minecraft-Version bleiben erhalten.

## English

Security update for zlib. Fixes the two reported vulnerabilities, CVE-2026-76844 and CVE-2026-85091, in the manager image's compression library.

For an existing installation, follow the [update guide](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/v1.0.2/docs/AKTUALISIEREN.md#english). Your world, mods and Minecraft version are retained.
