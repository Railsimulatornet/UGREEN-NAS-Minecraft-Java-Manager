# MCJ Manager 1.0.1

## Deutsch

Hallo zusammen!

Der MCJ Manager ist aus unserer eigenen Minecraft-Runde auf dem UGREEN NAS entstanden. Damit könnt ihr euren Minecraft-Java-Server über den Browser verwalten – am PC oder auf dem Smartphone, auf Deutsch oder Englisch.

Ihr könnt den Server starten und stoppen, Spieler freigeben, Mods verwalten, Welten wechseln und Backups erstellen oder wiederherstellen. Für eure Mitspieler erstellt der Manager ein passendes Clientpaket. Zur Anmeldung verwendet ihr ein Passwort und wahlweise einen E-Mail-Code oder eine Authenticator-App.

### Minecraft, Modloader und Java

Für diese Version sind die folgenden neun Kombinationen mit Besucherschutz geprüft:

| Minecraft | Fabric | Forge | NeoForge | Java |
|---|---|---|---|---|
| 1.20.1 | 0.20.1 | 47.4.28 | 47.1.106 | 17 |
| 1.21.1 | 0.20.1 | 52.1.20 | 21.1.265 | 21 |
| 26.3 | 0.20.1 | 66.1.0 | 26.3.0.99 | 25 |

Jede Zeile enthält drei getrennte Möglichkeiten: Fabric, Forge oder NeoForge. Minecraft 1.20.1 verwendet Java 17, 1.21.1 Java 21 und 26.3 Java 25. Bei NeoForge für 1.20.1 ist ausdrücklich die historische Version 47.1.106 gemeint; sie ist nicht mit Forge 47.4.28 austauschbar. Weitere Katalogeinträge gelten nicht automatisch als unterstützt. Zusätzliche Mods müssen zum gewählten Stand passen.

### Was wurde korrigiert?

Neben der Unterstützung für die drei Modloader sind der Besucherschutz, die Wiederherstellung und das saubere Stoppen des Servers überarbeitet worden. Konsolenbefehle funktionieren auch dann, wenn Forge 1.21.1 keine Textantwort zurücksendet; längere Antworten werden vollständig angezeigt. Außerdem werden besondere Dateitypen in Weltdaten sofort abgewiesen, damit sie die Weltverwaltung nicht blockieren können.

Das Release-ZIP enthält die Installationsunterlagen und UGOS-Vorlagen, kein Docker-Image. UGOS lädt das Manager-Image `railsimulatornet/ugreen-nas-minecraft-java-manager:1.0.1` separat von [Docker Hub](https://hub.docker.com/r/railsimulatornet/ugreen-nas-minecraft-java-manager).

Ihr benötigt ein UGREEN NAS mit Intel- oder AMD-Prozessor, UGOS und Docker (`linux/amd64`). Die Einrichtung erfolgt über die Docker-Projektverwaltung von UGOS. Das feste Manager-Image trägt die Version `1.0.1`; der geprüfte Updatekanal heißt `stable`.

**Bei einem Update müssen Manager, Steuerungsdienst und Minecraft laufen und gesund angezeigt werden.** Startet einen absichtlich gestoppten Minecraft-Server vorher. Bei Startfehlern helfen die Containerprotokolle in UGOS; startet keine Neuinstallation über euren vorhandenen Daten. Das Manager-Update ersetzt weder Welt noch Mods oder Minecraft-Laufzeit. Die Anleitung beschreibt auch den Rückfall auf den vorherigen Stand.

### Optionale Create-Zugkorrektur

Die Clientdatei 1.0.5 gehört ausschließlich zu der dokumentierten Kombination aus Minecraft 26.3, NeoForge und Create Adapted 1.31. Sie korrigiert die Darstellung für Fahrer, Mitfahrer und Zuschauer. Sie ist kein allgemeiner Fix für Fabric oder Forge. Quellcode und Lizenz liegen im selben Downloadordner.

### Vor dem Einrichten

Der Manager verwaltet einen Minecraft-Server pro NAS; ein ARM-Image ist nicht enthalten. Der Steuerungsdienst benötigt Docker-Rechte auf dem NAS. Gebt deshalb nur vertrauenswürdigen Personen Administratorzugriff und bewahrt wichtige Backups zusätzlich außerhalb des NAS auf. Bekannte Paketbefunde und ihre Bewertung stehen in der [Sicherheitsdokumentation](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/security/IMAGE-SECURITY.md).

Das Projekt ist unabhängig entstanden und keine offizielle Software von UGREEN, Mojang oder Microsoft. Jeder Spieler benötigt eine eigene Minecraft-Java-Lizenz.

## English

Hello everyone!

MCJ Manager started as a way to manage our own Minecraft server on a UGREEN NAS. It lets you look after your Minecraft Java server in a browser, on a computer or phone, in German or English.

You can start and stop the server, approve players, manage mods, switch worlds, and create or restore backups. The manager can also export a matching client pack for your players. Sign-in uses a password plus either an email code or an authenticator app.

### Minecraft, mod loaders and Java

These nine combinations have been tested with visitor protection:

| Minecraft | Fabric | Forge | NeoForge | Java |
|---|---|---|---|---|
| 1.20.1 | 0.20.1 | 47.4.28 | 47.1.106 | 17 |
| 1.21.1 | 0.20.1 | 52.1.20 | 21.1.265 | 21 |
| 26.3 | 0.20.1 | 66.1.0 | 26.3.0.99 | 25 |

Each row offers three separate choices: Fabric, Forge or NeoForge. Minecraft 1.20.1 uses Java 17, 1.21.1 uses Java 21 and 26.3 uses Java 25. NeoForge for 1.20.1 means the historical version 47.1.106; it is not interchangeable with Forge 47.4.28. Other catalogue entries are not automatically supported. Additional mods must match your chosen versions.

### What has been fixed?

Alongside support for all three mod loaders, this version includes corrections to visitor protection, restoration and clean server shutdown. Console commands now complete when Forge 1.21.1 returns no text, and longer responses are displayed in full. Special file types in world data are rejected immediately so that they cannot leave world management stuck.

The release ZIP contains the installation documents and UGOS templates, not a Docker image. UGOS downloads the manager image `railsimulatornet/ugreen-nas-minecraft-java-manager:1.0.1` separately from [Docker Hub](https://hub.docker.com/r/railsimulatornet/ugreen-nas-minecraft-java-manager).

You need an Intel or AMD UGREEN NAS with UGOS and Docker (`linux/amd64`). Setup uses the UGOS Docker project interface. The fixed manager image tag is `1.0.1`; `stable` is the tested update channel.

**Before updating, the manager, controller and Minecraft must all be running and shown as healthy.** Start an intentionally stopped Minecraft server first. If a service fails to start, check its container logs in UGOS; do not run first-time setup over existing data. A manager update leaves worlds, mods and the Minecraft runtime unchanged. The guide also explains rollback to the previous version.

### Optional Create train correction

Client file 1.0.5 applies only to the documented Minecraft 26.3, NeoForge and Create Adapted 1.31 combination. It corrects rendering for drivers, passengers and observers. It is not a general fix for Fabric or Forge. Source code and its licence are in the same download folder.

### Before you begin

The manager operates one Minecraft server per NAS. No ARM image is included. The controller needs Docker access on the NAS, so grant administrator access only to people you trust and keep additional copies of important backups outside the NAS. Known package findings and their assessment are described in the [security documentation](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/security/IMAGE-SECURITY.md).

This is an independent project, not official UGREEN, Mojang or Microsoft software. Each player needs their own Minecraft Java licence.
