# MCJ Manager 1.0.1

## Deutsch

Hallo zusammen!

Mit Version 1.0.1 habe ich zwei Fehler in der Backup-Verwaltung korrigiert.

„Löschbare Einträge auswählen“ konnte bisher auch geschützte Sicherungen auswählen. Beim Löschen kam dann eine Fehlermeldung. Die Auswahl und die Löschprüfung berücksichtigen jetzt dieselben Schutzregeln.

Außerdem blieben ältere Backup-Archive wegen Verweisen auf frühere Tests, Änderungen oder Wiederherstellungen dauerhaft liegen. Diese alten Verweise verlängern die eingestellte Aufbewahrung jetzt nicht mehr unbegrenzt. Nach einer erfolgreichen Sicherung werden abgelaufene Archive bereinigt. Die zwei neuesten Archive und Sicherungen, die ein ausstehender Auftrag noch benötigt, bleiben erhalten. Kleine Verlaufseinträge bleiben zur Übersicht bestehen.

**Bitte vor dem Update prüfen:** Ist deine Aufbewahrung beispielsweise auf vier Tage eingestellt, werden danach auch ältere Archive aus früheren Änderungen bereinigt. Kopiere Sicherungen, die du dauerhaft behalten möchtest, vorher an einen anderen Ort.

Außerdem enthält das Image die APT-Sicherheitskorrektur 3.0.4. Die weiterhin vorhandenen Paketmeldungen und ihre Bewertung stehen in den [Sicherheitshinweisen](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/security/IMAGE-SECURITY.md).

Die neun unterstützten Kombinationen bleiben gleich: Minecraft 1.20.1 mit Java 17, 1.21.1 mit Java 21 und 26.3 mit Java 25, jeweils mit Fabric, Forge oder NeoForge. Die genauen Loader-Versionen stehen in der [Kompatibilitätsübersicht](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/KOMPATIBILITAET.md).

Für eine vorhandene Installation bitte die [Update-Anleitung](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/AKTUALISIEREN.md) verwenden. Das Update ersetzt Manager und Steuerungsdienst; Welt, Mods und Minecraft-Version bleiben erhalten. Alle drei Dienste müssen vorher laufen und gesund angezeigt werden.

Die [Installationsunterlagen](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/releases/download/v1.0.1/MCJ-Manager-1.0.1.zip) enthalten Vorlagen und Handbücher, kein Docker-Image. UGOS lädt `railsimulatornet/ugreen-nas-minecraft-java-manager:1.0.1` separat von Docker Hub. Unterstützt wird `linux/amd64` auf Intel-/AMD-NAS.

Danke für eure Rückmeldungen und viel Spaß beim Spielen! 😊

## English

Hello everyone!

Version 1.0.1 fixes two issues in backup management.

“Select deletable items” could previously select protected backups, causing an error when deleting them. Selection and deletion now use the same protection rules.

Older backup archives could also remain indefinitely because they were linked to past tests, changes or restores. These old references no longer extend the configured retention period without a limit. Expired archives are cleaned up after a successful backup. The two newest archives and backups still needed by a pending job are retained. Small history records remain for reference.

**Please check before updating:** If retention is set to four days, for example, older archives from past changes will now also be cleaned up. Copy any backups you want to keep permanently to another location first.

The image also includes the APT 3.0.4 security fix. Remaining package findings and their assessment are documented in the [security notes](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/security/IMAGE-SECURITY.md#english).

The nine supported combinations are unchanged: Minecraft 1.20.1 with Java 17, 1.21.1 with Java 21 and 26.3 with Java 25, each with Fabric, Forge or NeoForge. Exact loader versions are listed in the [compatibility guide](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/KOMPATIBILITAET.md).

For an existing installation, follow the [update guide](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/blob/main/docs/AKTUALISIEREN.md#english). The update replaces the manager and controller; your world, mods and Minecraft version are retained. All three services must be running and healthy before updating.

The [installation pack](https://github.com/Railsimulatornet/UGREEN-NAS-Minecraft-Java-Manager/releases/download/v1.0.1/MCJ-Manager-1.0.1.zip) contains templates and manuals, not a Docker image. UGOS downloads `railsimulatornet/ugreen-nas-minecraft-java-manager:1.0.1` separately from Docker Hub. The supported platform is `linux/amd64` on Intel/AMD NAS devices.

Thanks for your feedback, and enjoy playing! 😊
