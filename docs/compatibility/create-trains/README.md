# Create-Zugfahrten / Create train journeys

[Deutsch](#deutsch) · [English](#english)

## Deutsch

Die optionale Clientkorrektur **1.0.4** behebt einen Positionskonflikt bei sitzenden Create-Zugfahrten. Sie wird im Manager bewusst zum Clientpaket hinzugefügt. Installiere sie ausschließlich auf dem Minecraft-Client, zusammen mit den passenden Dateien aus dem Paket.

Unterstützt wird Minecraft **26.3**, NeoForge **26.3.0.99**, Java **25** und Create Adapted **1.31** mit einer der unten aufgeführten Dateiprüfsummen. Andere Versionen werden beim Start zurückgewiesen. Prüfe die Korrektur vor einem Create-Update erneut.

Die Korrektur betrifft die normale Positionssynchronisierung eines sitzenden lokalen Fahrgasts. Zugsteuerung und Serverberechtigungen bleiben maßgeblich. Start sowie ruhige Vorwärts- und Rückwärtsfahrt wurden mit der passenden Konfiguration bestätigt. Das ist keine allgemeine Freigabe weiterer Create-Versionen.

Quellcode und Bauanleitung: [position-sync-1.0.4](position-sync-1.0.4/README.md). Lizenz: [MIT](position-sync-1.0.4/LICENSE). Herkunft und Funktionsumfang: [NOTICE](position-sync-1.0.4/NOTICE).

## English

The optional **1.0.4** client correction fixes a position conflict during seated Create train journeys. It is added deliberately to the client pack in the manager. Install it only on the Minecraft client, together with the matching pack files.

It supports Minecraft **26.3**, NeoForge **26.3.0.99**, Java **25**, and Create Adapted **1.31** with one of the file checksums below. Other versions are rejected at startup. Review the correction again before updating Create.

The correction affects ordinary position synchronization for a local seated passenger. Train controls and server permissions remain authoritative. Startup and smooth forward and reverse journeys have been confirmed with the matching configuration. This does not approve other Create versions.

Source and build instructions: [position-sync-1.0.4](position-sync-1.0.4/README.md). License: [MIT](position-sync-1.0.4/LICENSE). Origin and scope: [NOTICE](position-sync-1.0.4/NOTICE).
