# Create-Zugfahrten / Create train journeys

[Deutsch](#deutsch) · [English](#english)

## Deutsch

Die optionale Clientkorrektur **1.0.5** behebt einen Positionskonflikt bei Create-Zugfahrten für Fahrer, Mitfahrer und Zuschauer außerhalb des Zuges. Sie wird bewusst zum Clientpaket hinzugefügt. Installiere sie ausschließlich auf dem Minecraft-Client, zusammen mit den passenden Dateien aus dem Paket.

Unterstützt wird Minecraft **26.3**, NeoForge **26.3.0.99**, Java **25** und Create Adapted **1.31** mit einer der unten aufgeführten Dateiprüfsummen. Andere Versionen werden beim Start zurückgewiesen. Prüfe die Korrektur vor einem Create-Update erneut.

Die Korrektur betrifft die normale Positionssynchronisierung bereits initialisierter Create-Wagen. Zugsteuerung und Serverberechtigungen bleiben maßgeblich. Ruhige Bewegung für Fahrer und Zuschauer wurde mit echten Clients bestätigt. Das ist keine allgemeine Freigabe weiterer Create-Versionen.

Quellcode und Bauanleitung: [position-sync-1.0.5](position-sync-1.0.5/README.md). Lizenz: [MIT](position-sync-1.0.5/LICENSE). Herkunft und Funktionsumfang: [NOTICE](position-sync-1.0.5/NOTICE).

## English

The optional **1.0.5** client correction fixes a position conflict during Create train journeys for drivers, passengers and observers outside the train. It is added deliberately to the client pack. Install it only on the Minecraft client, together with the matching pack files.

It supports Minecraft **26.3**, NeoForge **26.3.0.99**, Java **25**, and Create Adapted **1.31** with one of the file checksums below. Other versions are rejected at startup. Review the correction again before updating Create.

The correction affects ordinary position synchronization for initialized Create carriages. Train controls and server permissions remain authoritative. Smooth movement for drivers and observers has been confirmed with actual clients. This does not approve other Create versions.

Source and build instructions: [position-sync-1.0.5](position-sync-1.0.5/README.md). License: [MIT](position-sync-1.0.5/LICENSE). Origin and scope: [NOTICE](position-sync-1.0.5/NOTICE).
