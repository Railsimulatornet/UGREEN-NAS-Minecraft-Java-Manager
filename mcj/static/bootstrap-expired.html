Einrichtungszugang abgelaufen

Zum Schutz deines NAS gilt ein Einrichtungszugang vier Stunden. Du kannst einen neuen Zugang direkt in UGOS anfordern.

So geht es weiter

  1. Öffne in UGOS Docker → Projekt.
  2. Wenn noch keine Installation läuft: Beende das Projekt mcj_einrichtung und starte es erneut.
  3. Öffne im NAS-Dateimanager mcj-einrichtung/EINRICHTUNGSCODE.txt. Dort steht jetzt der neue Code.
  4. Lade diese Seite neu und öffne die Einrichtung mit dem neuen Code.

Hast du die Installation bereits gestartet? Lasse sie weiterlaufen und prüfe das Bereitstellungsprotokoll in UGOS. Starte während einer laufenden Installation nicht neu.
